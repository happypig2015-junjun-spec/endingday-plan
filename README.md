# 末日回声 · ECHO OF DOOMSDAY

一个使用 **标准 C++20** 编写的多分支末日生存文字游戏。剧情完全**数据驱动**，
拥有 **107 个互相关联的场景节点**（含 24 个死亡回溯点）、**9 条三档线索**、
**12 件关联道具**与 **3 个结局**（含真结局）。全部剧情**逐字显示（slowprint）**。

---

## 一、故事背景

"灰雾日"后第 7 天，城市因一种诡异瘟疫沦陷。你在地铁应急避难所醒来，
发现自己拥有**时间回溯**能力：每次死亡，意识都回到避难所醒来的瞬间——
世界重置、伤痕消失，唯有**记忆与线索保留**。

你一次次走进灰雾，把用命换来的信息拼成真相。最终你会发现：
**你自己，就是这一切的起点。**

---

## 二、核心特性

- **逐字显示 slowprint**：字符逐个输出，逗号/句号/省略号自动停顿；
  播放期间按任意键可立即快进，提前输入的数字不会丢失。
- **多分支选择**：107 个场景、每个场景 2~7 个选项，错误选择会导致死亡。
- **死亡回溯机制**：死亡不是 Game Over，而是回到锚点、保留全部线索，
  可反复探索不同分支。
- **三档线索系统**：
  - 基础线索（3 条）：描述"发生了什么"（现象层）；
  - 进阶线索（3 条）：揭示"谁在做、为什么"（阴谋层）；
  - 高级线索（3 条）：触及"末日的本质"（真相层）。
- **关联道具网络**：12 件道具（撬棍 / 门禁卡 / 防护服 / 手枪 / 电子管 /
  密码本……）跨区域解锁，把所有分支串成一张网。
- **三个结局**：
  - 《漫长的等待》：集齐 3 条基础线索后推理；
  - 《撕幕者》：集齐 3 条进阶线索后推理；
  - **真结局《锚点之外》**：**基础 + 进阶 + 高级共 9 条线索全部获得**，
    进入锚点核心关闭循环。
- **高可拓展性**：剧情与逻辑彻底分离，新增内容几乎只改 `StoryData.cpp`。
- 完整支持中文（UTF-8），跨平台（Linux / macOS / Windows）。

## 三、目录结构

```
echo-of-doomsday/
├── include/
│   ├── GameTypes.h    # 数据结构：Clue / Choice / Scene / Ending（聚合体）
│   ├── Terminal.h     # 终端接口：slowprint、颜色、菜单读取
│   ├── StoryData.h    # 剧情数据库只读接口
│   └── GameEngine.h   # 游戏引擎接口
├── src/
│   ├── Terminal.cpp   # 终端实现（逐字输出 / 跨平台键盘检测 / UTF-8）
│   ├── StoryData.cpp  # ★ 全部剧情数据（拓展时主要改这里；网盘上分为 3 个分卷）
│   ├── GameEngine.cpp  # 引擎实现（场景流转 / 线索 / 结局 / 回溯）
│   └── main.cpp        # 程序入口
├── Makefile
└── README.md
```

> **网盘分卷说明**：受网盘文本上传单次 2 万字限制，`StoryData.cpp`
> 在 `src/` 目录下被拆成 `StoryData.part1.cpp`、`StoryData.part2.cpp`、
> `StoryData.part3.cpp` 三段。下载后在该目录执行：
> `cat StoryData.part1.cpp StoryData.part2.cpp StoryData.part3.cpp > StoryData.cpp`
> 即可还原完整文件。

## 四、编译与运行

需要支持 C++20 的编译器（GCC 11+ / Clang 13+ / MSVC 2021+）。

```bash
make          # 编译生成 ./doomsday
make run      # 编译并运行
make clean    # 清理
```

或手动编译：

```bash
g++ -std=c++20 -O2 -Wall -Wextra -Wpedantic -Iinclude \
    src/main.cpp src/Terminal.cpp src/StoryData.cpp src/GameEngine.cpp -o doomsday
./doomsday
```

**操作**：输入选项前的数字并回车；
- `L`：随时查看线索本（含未获得线索的占位与进度）；
- `Q`：退出游戏。

## 六、拓展教程（高可拓展性）

新增内容几乎只改 `StoryData.cpp`：在 `kClues` 加线索、在 `kScenes` 加场景、
在 `kEndings` 加结局，引擎无需改动。详见源码内详细注释。
